# Зеленая Зона - Пиксельный Платформер

**Зеленая Зона** - это 2D платформер с пиксельной графикой, созданный с использованием библиотеки pygame. Игра включает механики паркура, специальных способностей и исследования уровней.

## Особенности

- **Стильная пиксельная графика** с качественно отрисованными ассетами
- **Плавное управление персонажем** с физикой движения
- **Уникальные механики**:
  - Использование крюка для перемещения и преодоления препятствий
  - Рывок (dash) для быстрого перемещения и уклонения
  - Сбор предметов и взаимодействие с объектами мира
- **Красивый фон с эффектом параллакса**
- **Интуитивный пользовательский интерфейс** с разными меню и настройками
- **Адаптивное разрешение** для работы на различных устройствах

## Управление

- **W, A, S, D или стрелки** - перемещение персонажа
- **Пробел** - прыжок
- **Левая кнопка мыши** - выпустить крюк в направлении курсора
- **R** - отцепить крюк
- **Левый Shift** - рывок (dash) в текущем направлении
- **Esc** - пауза

## Требования

- Python 3.6+
- Pygame 2.0+

## Установка

1. Клонируйте репозиторий:
   ```
   git clone [URL репозитория]
   ```

2. Перейдите в директорию проекта:
   ```
   cd [название проекта]
   ```

3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск

Запустите игру с помощью команды:
```
python main.py
```

## Структура проекта

```
├── main.py              # Главный файл для запуска игры
├── requirements.txt     # Зависимости проекта
└── src/                 # Исходный код
    ├── Assets/          # Графические ассеты
    │   ├── AnimatedObjects/
    │   ├── Background/
    │   ├── Objects/
    │   └── Tiles/
    ├── Levels/          # Описание уровней
    ├── Resources/       # Дополнительные ресурсы (шрифты и т.д.)
    ├── background.py    # Класс для фона с эффектом параллакса
    ├── game.py          # Основной игровой класс
    ├── game_objects.py  # Классы игровых объектов
    ├── level.py         # Класс обработки уровней
    ├── main.py          # Логика запуска игры
    ├── player.py        # Класс игрока и его механики
    ├── tileset.py       # Обработка тайлсетов
    ├── ui.py            # Классы пользовательского интерфейса
    └── utils.py         # Вспомогательные функции
```

## Источники ассетов

Графические ассеты взяты из пакета "Green Zone Tileset Pixel Art" и адаптированы для использования в проекте.
